## 動きの仕組み（ここが本題）

1. **日**＝LIVEモードでは今日の日付に一致する日。1〜15日目＝台本の trades.json、**16〜30日目（9/14〜10/2）＝ストーリーカレンダーの「9/14以降の残高計画」**（差引・残高はその表どおり。時刻と1回ごとの損益は決定論で割り付け。台本ができて trades.json に入ればそちらが優先）。**土日は休場＝取引なし・前営業日の終値で止まる**（AIはSTANDBY表示）
2. **残高（大きい数字）**＝`開始残高 ＋ その時刻までに決済した取引の損益の合計`＝**確定額だけ**（含み損益は別枠）。決済の瞬間に段差で動き、ほかの時間は動かない。**23:00の投稿時点で必ず台本の「残高」と一致する**
3. **約定〜決済の間**＝含み損益が動く（チャートの値動きから算出。損切り上限=残高の0.6%を絶対に超えない）。決済の瞬間に台本の損益で確定してログに載る
4. **チャート**＝1分足を日ごと・板ごとに決定論で生成（リロードしても同じ）。**取引の前後だけボラが2〜3倍**になり、約定→決済の値動きが損益の符号・大きさと一致する（勝ちのBUYなら上がって決済）。他の板も少し連動して動く
5. **AI CORE**＝SCANNING → SIGNAL（約定2.5分前）→ HOLDING → EXITING を取引に同期。中央は**イヴの脳**（EVE_COREの点群脳を小型化。待機＝シアン／保有＝琥珀で激しく脈打つ／決済＝マゼンタ）。スマホでも表示
6. **画面に「何日目」「日付」「時刻」「REPLAY」などの設定情報は出さない**（2026-09-06 本人指示・見せる用）。それらは ⚙（`G`キー）の**裏設定**の1行目にだけ出る
7. **時刻は画面のどこにも出さない**（2026-09-07 本人指示）。チャート下の時間軸（11:00 等）は目盛りの線だけ／約定ログの左端は時刻ではなく**本日の通し番号**／シグナルフィードは行頭の時刻を廃止。チャート番号の表記は `#1` から `CH1` に統一

## 設定（⚙ または `G` キー／URLパラメータ）

| 項目 | 値 | 例 |
|---|---|---|
| `acct` | `plan`（**既定**・100万丸投げ企画）／`main`（メイン口座・218.09倍） | `?acct=main` |
| `mode` | `live`（**実時刻＝NOW・既定**。チャートも1分に1本しか進まない）／`replay`（仮想時刻・確認用） | `?mode=replay&t=14:30&speed=60` |
| `day` | `auto`（今日）／`1`〜`15` | `?day=9` |
| `t` `speed` | REPLAYの開始時刻・速度（×1既定／×5／×7／×10／×60／×240） | 1日を6分で流すなら `speed=240` |
| `panes` | `auto`（その日の枚数=台本の裏設定）／`1`／`2`／`3`／`random`（7分ごとに変わる） | `?panes=3` |
| `layout` | 3枚の並び `focus`（1大＋2小・既定）／`cols`（3列） | |
| `labels` | `index`（**既定・謎の数字**＝独自インデックス。実レートとは無関係）／`none`（数値を一切出さない） | |
| `cw` | ローソクの太さ `5`／`7`／`10` | |

設定は localStorage `cash_cfg` に残る。

キー: `1` `2` `3` 枚数／`0` AUTO／`R` RANDOM／`[` `]` 前後の日／`L` LIVE⇄REPLAY／`Space` 一時停止／`-` `+` 速度／`G` 設定。

## 守っていること（シリーズの禁止事項）

- **銘柄名・レートは出さない**。**黒塗りモザイクは全廃**（2026-09-07 本人指示）。価格軸・TP/SL・凡例に出るのは
  `fmtP()` が作る**独自インデックス**だけ＝「基準からの変化率を0.01%＝1.00ポイントに写した数字」で、実在のレートとは無関係。`none` にすれば数値ごと消える
- **通算回数を出さない**（W3から）。表示は本日の回数・勝敗だけ
- **「変えない自慢」を書かない**（RISK DESK の文言は上限・板数・手動不可・事前コミットのみ）
- 数字は `trades.json` から1円も動かさない。台本側を直したら `python build_data.py`
- メイン口座も**同じ取引を倍率で写しただけ**＝勝敗・回数・時刻・チャートは企画と完全に同じ。ここがズレると2つ並べたとき嘘になる
