# 取引履歴サイト（2026-09-18 更新）

口座ごとに開始日を分ける。企画口座は2026年8月24日の100万円スタートから、メイン口座は従来の2024年9月2日からの過去2年分を含めて表示する。いずれもシミュレーション設定データ。

- `../data.js` の両口座の約定・決済時刻、売買、チャート、損益、決済後残高をそのまま使う。
- 元本は企画1,000,000円／メイン100,000,000円。累計損益は各元本を基準に計算。
- メインの9月1日より前は従来の履歴を維持（2026/8/21まで生成履歴＋8/24〜8/31の既存設定）。9/1以降は稼働画面のメイン口座データと一致。
- 両口座とも「全期間」で各開始日から選択した「今日」まで表示。期間フィルターは維持。
- ⚙内の「今日として扱う日付」で表示の終点を選択。その日終日までの決済を表示し、それ以降は除外する。
- 1ヶ月・3ヶ月等の期間は、選択した「今日」を終点に計算する。土日も指定可能。
- 稼働画面の履歴リンクから開くと、選択日と口座をURLで引き継ぐ。
- 口座切り替えは⚙内のプルダウン（企画口座／メイン口座）。画面上部の口座1・2ボタンは撤去。
- 日付・口座・テーマはブラウザに保存。URL指定があればそちらが優先。
- 白／黒テーマ、CSV／JSON読み込み、期間・勝敗・売買・CHフィルターは維持。

## 3つ目の口座: ApexGrid（バックテスト）（2026-10-03 追加）

⚙ の「表示する口座」に **ApexGrid（バックテスト）** を足した。有料版EA ApexGrid_v2 を **25万円・追加入金なしで 2018年1月2日から動かした場合のバックテスト**（過去の値動きでの計算。安全装置＝含み損が残高の45%で全部決済、も計算に入っている）。

- **実際の口座の成績ではない。** 選ぶと、見出しの横に「バックテスト」の印、残高の上に説明の枠が必ず出る（企画・メインには出ない）。この印と説明は外さない。
- データは `apexgrid.js`（`build_apexgrid.py` が作る）。`history.js` とは別ファイルなので、`build_history.py` を叩き直しても消えない。企画・メインの数字には一切さわっていない（追加の前後で、公開中の画面と数字が1つも変わらないことを確認済み）。
- この口座だけの表示: 板の代わりに通貨ペア名（GBPUSD・EURUSD・GBPAUD・AUDUSD）／ロットは小数2桁／時間帯は0〜23時・曜日は土曜（金曜の夜の続き）まで／資産推移に「含み損を入れた金額（最低）」の線／落ち込みは含み損込み。
- URL: `history/?acct=apex`
- 元データと作り方: `システム関連/20_ApexGrid（有料版）/さらなる最強EA_2026-09-20/参考資料…/ツール/`（`v2_8y_run.py` → `v2_8y_page.py` → ここの `build_apexgrid.py`）。1回ずつの取引を日ごとにたどれる詳しいページ（取引日誌）は、同じフォルダの `08_25万円_8年取引日誌と安全装置.md` に場所がある。
- **データを新しくしたいとき（Windows だけ。値動きデータがそこにしか無い）**:
  1. `python v2_8y_run.py <最後の日 例 2026.10.31> --guard 45`（システム関連の ツール フォルダで）
  2. `python v2_8y_page.py`
  3. `python build_apexgrid.py`（このフォルダで）
  4. 親フォルダの `deploy.ps1`
