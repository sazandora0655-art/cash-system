# 取引履歴サイト（2026-09-18 更新）

2026年9月1日以降のシミュレーション設定データを表示する。過去2年分の生成履歴は表示対象から外した。

- `../data.js` の両口座の約定・決済時刻、売買、チャート、損益、決済後残高をそのまま使う。
- 開始残高は9/1始値（企画 1,054,519円／メイン 229,984,005円）。期間損益の基準もこの開始残高。
- ⚙内の「今日として扱う日付」で表示の終点を選択。その日終日までの決済を表示し、それ以降は除外する。
- 1ヶ月・3ヶ月等の期間は、選択した「今日」を終点に計算する。土日も指定可能。
- 稼働画面の履歴リンクから開くと、選択日と口座をURLで引き継ぐ。
- 口座切り替えは⚙内のプルダウン（企画口座／メイン口座）。画面上部の口座1・2ボタンは撤去。
- 日付・口座・テーマはブラウザに保存。URL指定があればそちらが優先。
- 白／黒テーマ、CSV／JSON読み込み、期間・勝敗・売買・CHフィルターは維持。

## データ更新

`python3 ../build_data.py` → `python3 build_history.py`。
公開先URLは従来と同じ。公開には親フォルダのdeploy.sh（Mac）／deploy.ps1（Windows）を使用する。

例: `history/?acct=plan&asof=2026-10-07&theme=dark`

`取引履歴_入力.csv` がある場合は既存の外部CSV入力経路が優先される。ブラウザに読み込んだデータも、明示的に戻すまで維持する。
